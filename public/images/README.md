# صور وهوية المنصة (Brand Assets)

ضع هنا صور هوية المنصة والعلامة التجارية:

- `logo.svg` أو `logo.png` -> لوجو المنصة الرسمي بدقة عالية وخلفية شفافة.
- `og-card.jpg` -> صورة كارت المعاينة الرسمية للمنصة عند المشاركة على السوشيال ميديا (1200x630px).
- `wax-seal-gold.png` -> خامة الختم الشمعي الذهبي.
- `wax-seal-burgundy.png` -> خامة الختم الشمعي العنابي.
- `wax-seal-pearl.png` -> خامة الختم الشمعي اللؤلؤي.
